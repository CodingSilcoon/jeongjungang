- 출발 알람 설정은 아직 페이지 시안 단계입니다. 이번 변경으로 알람 설정 기능을 새로 구현한 것은 아닙니다.

## 앱에 적용한 시작 화면

- 레이아웃: `android/app/src/main/res/layout/activity_main.xml`
- 문구·색상·스타일·간격: `android/app/src/main/res/values/start_screen.xml`
- 일러스트·버튼 배경: `android/app/src/main/res/drawable/start_*.xml`
- 버튼 동작: `android/app/src/main/java/com/jeongjungang/ui/MainActivity.java`

앱은 HTML을 띄우는 대신 Java + XML + ViewBinding으로 구현합니다. 시안의 폰 테두리와 가짜 상태 표시줄은 앱에 포함하지 않습니다. 실제 시스템 영역을 피하고, 작은 화면과 큰 글꼴에서는 세로 스크롤을 제공합니다.

현재 '바로 만날 곳 찾기'는 출발지 입력, '약속 만들기'는 약속 생성 화면으로 연결됩니다. '초대 참여'는 준비 중 안내를 표시합니다.

## 출발지 입력 화면

- 시안: `origin-input.html`
- 구현: `OriginActivity.java`, `activity_origin.xml`, `item_origin.xml`
- 문구와 스타일: `res/values/origin_screen.xml`
- 내 위치와 친구 1로 시작해 총 10명까지 추가합니다. 내 위치는 현재 GPS 자동 감지가 아니라 직접 선택하는 출발지입니다.

- 모든 출발지를 선택하고 '만날 곳 찾기'를 누르면 추천 기준 바텀시트를 엽니다. 바깥 터치·뒤로가기·아래로 쓸어내리기로 닫아도 입력과 선택 기준을 유지합니다.
- 팝업 레이아웃은 `sheet_origin_criteria.xml`이며, 확인하면 선택 기준과 출발지를 추천 결과 화면에 전달합니다.
- 회전·프로세스 재생성 시 입력한 출발지 이름·좌표, 화면 단계와 추천 기준을 복구합니다.

빌드와 실행 검증은 사용자 요청에 따라 직접 진행합니다.

- `MeetingViewModel.create`에 연결하며 서버 미설정 시 연결 필요 안내를 보여 줍니다. 생성 성공 때만 실제 초대 코드·링크를 표시하고 Android 공유창을 엽니다.
- 생성 중 중복 제출을 막고 실패 시 입력을 보존합니다. 회전 시 선택 항목과 생성 결과를 복원합니다.
- 생성 성공 후 약속 대기방으로 이동합니다. 초대 참여도 별도 화면에서 같은 대기방으로 연결합니다.

## 약속 대기방

- 구현: `MeetingRoomActivity.java`, `activity_meeting_room.xml`. API.md 6절과 기존 `MeetingViewModel`을 사용합니다.
- 약속 생성 후 진입하고, 시작 화면의 약속 만들기에서 저장된 참가 자격이 있는 약속을 다시 열 수 있습니다.
- 실제 참여자·출발지 현황은 화면이 보일 때 4초 간격으로 갱신합니다. 오류 시 이전 상태와 재시도를 표시하고, 만료·취소·내보내짐은 안내합니다.
- 방장은 약속 이름·목적·일시 수정, 참가자 내보내기, 취소가 가능합니다. 본인은 이름·출발지를 변경하고 나갈 수 있습니다. 취소·나가기·내보내기는 확인창을 거칩니다.
- 생성 응답의 초대 정보는 재진입을 위해 보관합니다. 조회 응답에 초대 정보가 없으므로, 이 기기에 코드가 없는 경우 공유 카드를 표시하지 않습니다. 토큰은 기존 암호화 저장소만 사용합니다.
- 출발지가 2곳 이상이면 실제 닉네임·좌표로 추천에 연결합니다. 미입력자는 제외 안내 후 진행하고 하단 팝업에서 추천 기준을 선택합니다. 확인 중 약속 버전이 바뀌면 다시 확인하도록 합니다.
- 추천 후보는 약속 확정 화면으로 연결합니다. 알람 설정 화면은 후속 작업입니다.
- 빌드·서버 연동 실행은 수행하지 않았습니다. XML 문법과 변경 공백만 확인했습니다.

- 선택 후보, 추천 기준, 상세 진입 상태와 스크롤 위치를 회전·프로세스 재생성 때 복원합니다.

- 대기방 상단 제목은 사용자 요청대로 '약속 만들기'로 변경했습니다.
- 빌드는 실행하지 않았으며 XML 문법과 변경 공백을 확인했습니다.
