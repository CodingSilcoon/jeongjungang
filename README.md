# 정중앙

"우리 모두 만나기 좋은 곳"을 찾아 주는 안드로이드 앱입니다. 지리적 정중앙이 아니라, 모두가 납득할 만한 만남 장소를 목표로 합니다.

출발지를 입력하면 후보 3곳을 골라 주고, 사람마다 걸리는 시간과 환승 횟수를 비교해서 친구에게 공유할 수 있습니다. 장소가 정해지면 출발 알람을 자동으로 걸어 주는 **책임 알람**도 함께 개발합니다.

> 상태: 개발 초기입니다. 추천 로직의 코어(좌표 중앙값, 지하철 그래프, 최단시간 탐색)까지 구현했고, 안드로이드 앱 화면과 서버는 아직 없습니다.

## 기능

**추천 (1단계, 서버 없음)**
1. 참가자 출발지 입력(주소 검색 또는 지도 핀)
2. 중앙값 주변 역을 후보로 뽑고, 각자 출발지에서 후보까지 걸리는 시간과 환승을 계산
3. "전체 이동시간 최소" 또는 "최대 이동시간 최소(한 명만 너무 멀지 않게)" 기준으로 후보 3곳과 선정 이유 제시
4. 카카오맵·네이버지도 딥링크, 공유

소요시간은 서울교통공사 공개 데이터로 계산한 **근사값**이고, 앱 화면에도 그렇게 표시합니다.

**초대 링크와 약속 목적 필터 (2단계)**: 링크로 참가자가 직접 위치를 입력하고, 식사·카페·술자리 같은 목적으로 장소를 거릅니다.

**책임 알람 (3단계)**: 참가자별 알람시각을 `약속시간 − 이동시간 − 준비시간`으로 자동 계산합니다. 정해진 시간 안에 알람을 안 끄면 같은 약속 멤버 전원의 폰이 울립니다. 서버가 기기 보고와 무관하게 직접 확인하고, 전원이 동의한 약속에서만 켜집니다. 자세한 설계는 [CLAUDE.md](CLAUDE.md)의 "확장: 책임 알람"에 있습니다.

## 범위

- 서울교통공사 1~8호선만 지원합니다. 9호선, 신분당선, 분당선, 경의중앙선, 공항철도 등은 지원하지 않습니다.
- 1호선은 서울역~청량리 구간만 포함됩니다.
- 안드로이드 전용입니다. 책임 알람은 iOS에서 원격 강제 알람을 보장할 수 없어 제외했습니다.

## 기술 스택

| 영역 | 사용 |
|---|---|
| Android | Java(Kotlin 사용 안 함), XML + ViewBinding, MVVM + ViewModel + LiveData, ExecutorService/Handler |
| 지도·주소 | 카카오맵 SDK, 카카오 로컬 |
| 서버 (2단계~) | Spring Boot 3.5 / Java 17, Redis, Docker. 3단계부터 RDB(MySQL 또는 Postgres)와 FCM |
| 데이터 | 서울 열린데이터광장 CSV 3종(앱에 번들) |

## 개발 환경

- JDK 17
- 백엔드: `cd backend && ./gradlew build` (Windows는 `gradlew.bat build`)
- 안드로이드: Gradle 프로젝트 파일(`build.gradle`, `AndroidManifest.xml` 등)이 아직 없습니다. Android Studio에서 프로젝트를 만든 뒤 `android/app/src`의 소스를 옮길 예정입니다. 코어 코드는 Android 의존성이 없어서 JUnit4만으로 테스트할 수 있습니다.

API 키(카카오, ODsay, FCM 서버 자격증명 등)는 저장소에 두지 않습니다. 환경변수나 `local.properties`로만 주입하고, 외부 API 키가 필요한 호출은 서버를 거칩니다.

## 로드맵

1. **추천 MVP(앱 단독)**: 코어 로직은 구현 완료. 후보 선정·점수화, 화면, 공유가 남았습니다.
2. **초대 링크, 약속 목적 필터**: 서버 도입(Redis 방 + TTL, 앱 링크, 폴링).
3. **책임 알람**: 서버 도메인과 Redis 에스컬레이션 스케줄러 → 앱 로컬 알람과 풀스크린 울림 → FCM → 이동시간 연동 → 실기기(삼성 포함) 테스트.
4. 후순위: 결제, 장거리, 다른 운영기관 노선.
